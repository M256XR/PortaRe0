## 冷却

- 方式：パッシブ（ヒートパイプ + 小型ヒートシンク）
- ヒートパイプ：3mm厚フラット銅製 / SoC → 90度曲げ → バッテリー上端の隙間（幅16mm）を通過
- ヒートシンク：14×9×4mm 程度 × 4個
- ファン：RP2040 #1 GP26（FAN_PWM）→ BSS138 → J6（2pin JST PH）
