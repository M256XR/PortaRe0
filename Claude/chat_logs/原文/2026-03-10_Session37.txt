## RP2040 水晶の配置距離

**Raspberry Pi RP2040 Hardware Design Guide の推奨:**

| 対象 | 推奨距離 |
|------|---------|
| 水晶本体（XIN/XOUTピンから） | **できるだけ近く、理想 ≤5mm** |
| 負荷キャップ（水晶の近く） | **水晶から ≤1mm** |

### なぜ厳しいか

- RP2040は12MHz発振（USB要求精度±2500ppm）
- XIN/XOUTトレースが長いと寄生容量↑ → 発振周波数ずれ
- 外来ノイズが乗るとジッタ増大 → USB不安定

### 現実的な許容ライン

- **≤5mm**: 問題なし（公式推奨範囲内）
- **5〜10mm**: 動く可能性が高いが要注意（実測で確認推奨）
- **>10mm**: USBが不安定になるリスクあり → 非推奨

### 注意事項
- XIN/XOUTトレースはGNDガードを引くこと
- 他のノイズ源（スイッチング電源・USB SS）から離す
- 負荷キャップはRPi公式の **18pF×2**（プロジェクト確定済み）

**結論: 水晶は5mm以内に収める。負荷キャップは水晶の両端に1mm以内で。**

## ルーティング 基本確認事項

### トレース幅の目安（JLCPCB 最小0.1mm）

| 信号種別 | 幅 |
|---------|-----|
| 一般信号線 | 0.1〜0.15mm |
| 3.3V/5V電源 | 0.3〜0.5mm |
| VSYS / 5V_SYS（最大5〜6A） | **1.5〜2.0mm以上** |
| VBAT（バッテリー → BQ25895） | **1.5mm以上** |
| スピーカー出力 | 0.3mm程度 |

### 層別ルール（確定済み）

| 層 | 用途 |
|----|------|
| F.Cu | COL線 + キースイッチのみ（IC配線NG） |
| In1 | GNDベタ（配線なし） |
| In2 | ROW線 + IC配線1層目 + USB3.0 SS + HDMI差動ペア |
| In3 | 電源ゾーン（VSYS/5V_SYS/3V3） + IC配線2層目 |
| In4 | GNDベタ（配線なし） |
| B.Cu | IC実装面 + IC配線 + PCIe差動ペア |

### 高速差動ペア（要インピーダンス管理）

| 信号 | 層 | インピーダンス | 等長 |
|------|----|------------|------|
| USB3.0 SS | In2 | 90Ω差動 | 不要（参考: ペア内±5mil以内） |
| HDMI | In2 | 90Ω差動 | **必要** |
| PCIe Gen3 x1 | B.Cu | 85〜90Ω差動 | **必要** |

### 重要ルール

1. **スイッチングノードループ最小化**: L1/L2/L4のSWピン側ループを最小に
2. **GNDビアをインダクタ直近に**: スイッチング電流のリターンパスを最短に
3. **水晶トレース**: GNDガード囲む・ノイズ源から離す
4. **アナログ音声**: デジタル信号とクロスしない（特にPCM5102A → TPA6132A2間）
5. **ESD保護（USBLC6）**: コネクタ入口の最初にルーティング（ICより前）

## ルーティング推奨順序

1. **GNDベタ埋め**（In1/In4）← 最初にやっておく
2. **電源幹線**（VBAT → BQ25895 → VSYS → TPS61023 → 5V_SYS）← 極太・最短
3. **3V3/5V_SYSプレーン**（In3ゾーン）
4. **スイッチングノード**（L1/L2/L4のSW側ループ）
5. **高速差動ペア**（USB3.0 SS / HDMI / PCIe）← インピーダンス管理が必要な箇所を早めに
6. **IC間信号線**（SPI / I2C / I2S等）
7. **一般信号線**（GPIO / LED / スイッチ等）
8. **デカップリングキャップのビア**

### 理由

CCがFPCにないと：
- SBCがRpを検出できない
- USB-C仕様上はCC未検出 = 500mA以下しか引いてはいけない
- SBCによっては起動しない・不安定になる可能性あり

J_USB_PWR（充電入力側）は5.1kΩ（Rd）でGNDに落としてますが、それはSBCが**受電側**の場合。今回はPCBがSBCに**供給する側**なのでRp（10kΩ）が必要です。

### 結論

ユーザーの案（CC入り）が正解です：
- Pin 1〜10: 5V
- Pin 11〜22: GND  
- Pin 23: CC1
- Pin 24: CC2

ちなみにHDMIコントローラーの必要電流は1Aなんだけど3pinでだいじょぶ層？

----------------------------------------

[Claude]
ギリギリです。

0.5mmピッチFPCは1pinあたり0.3〜0.5Aなので：
- 3pin × 0.3A = **0.9A**（最悪ケース）
- 3pin × 0.5A = 1.5A（最良ケース）

1Aぴったりだと余裕がないので**4〜5pinに増やす**のが安心です。GNDも同じく増やしておいてください。
