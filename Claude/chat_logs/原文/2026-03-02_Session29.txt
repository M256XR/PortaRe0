## 作業① audio.kicad_sch — 2.2nF追加（×2）

**場所**：TPA6132A2（U13付近）の左側にあるR8・R54（470Ω）のTPA6132A2側（出力側）ノード

```
追加する回路:
  R8(470Ω) → [ここに C_Small 2.2nF → GNDPWR]  → INL- pin
  R54(470Ω) → [ここに C_Small 2.2nF → GNDPWR] → INR- pin
```

手順：
1. R8の右側（TPA6132A2側）ノードにC_Small（Value: 2.2nF）を追加
2. そのCの下ピンにGNDPWRパワーシンボルを接続
