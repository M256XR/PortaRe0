ユーザーの直感は正しいです。**GNDを間に挟む方がベター**です。

**理由:**
- HDMI信号（特にTMDS差動ペア）は高周波なので、5V電源レールとの間にGNDバッファがあると**EMIカップリングを低減**できる
- HDMI標準でもGNDピンが差動ペアの間に挟まれている設計思想と一致する
- FPCケーブルは隣接導体間のクロストークが発生しやすいので、信号・電源間の分離は有効

**修正後のピン割り当て:**

| ピン | 接続先 |
|------|--------|
| Pin1〜19 | HDMI 19信号（変更なし） |
| **Pin20〜21** | **GND×2**（バッファ） |
| **Pin22〜24** | **5V_SYS×3**（並列） |

GNDで信号ブロックと電源ブロックを分離する形です。KiCadでの配置時はこの順で接続してください。

## J_FAN（RP2040制御）

RP2040 #1 の空きGPIO（GP26）でPWM制御できます。回路構成：

```
5V_SYS → ファン VCC
ファン GND → BSS138（Nch FET）drain
BSS138 source → GND
BSS138 gate → 10kΩプルダウン + RP2040 GP26
```

## J_SBC_HDMI（FPVケーブル断念）

水平型が2cm出っ張るなら筐体に収まらないですね。代替案：

**案A: Micro HDMI Type D メス SMD をスティフナーに直付け**
- A7ZのMicro HDMIオスが直接刺さる形
- FPC経由でメインPCBへ引き出し
- 出っ張りはコネクタ高さのみ（数mm）
- LCSCにMicro HDMI Dメス SMDが存在するか要確認

**案B: 垂直型FPVケーブル**
- ケーブルがFPCと平行に出る向きのもの
- 出っ張りが横方向になるので筐体次第では収まる可能性あり

**案C: Micro HDMI ライトアングルコネクタ**
- PCB上でケーブルが寝る形のコネクタ

案Aが一番スマートだと思いますが、どれが良さそうですか？
