## power系 配線幅の目安

設計上の電流値から計算します（JLCPCBデフォルト 1oz銅箔、10°C温度上昇基準）。

---

### ネット別 推奨幅（外層 / 内層）

| ネット | 最大電流 | 外層 (F.Cu/B.Cu) | 内層 (In3) |
|--------|---------|-----------------|-----------|
| **VBAT** (J4 ↔ BQ25895) | **5〜6A** | **1.5mm** | **2.5mm** or 銅塗り |
| **VSYS** (BQ25895 SYS ↔ TPS61023 #1) | **5〜6A** | **1.5mm** | **銅塗り必須** |
| **5V_SYS** (TPS61023 #1出力 ↔ 各IC) | ~3〜4A | 1.0mm | 銅塗り推奨 |
| **USB_5V_SYS** (TPS61023 #2出力) | ~0.9A | 0.4mm | 0.6mm |
| **3V3** (AP2112K出力) | ~0.6A | 0.3mm | 0.5mm |
| **3V3_M2** (RT9080出力) | ~1A | 0.4mm | 0.6mm |
| **3V3_HUB** (VL812内部) | ~0.3A | 0.2mm | 0.3mm |
| スイッチングノード (L1/L2/L4 ↔ IC) | ピーク大 | **1.0mm以上・短く** | — |

---

### 実用方針

**VSYS / 5V_SYS は銅塗りが現実的**
- In3を電源ゾーン層として設計済み → VSYS・5V_SYSはゾーン銅塗り（ベタ）で引く
- トレース幅計算より低インピーダンス・放熱にもなる

**スイッチングノード（L1/L2/L4のSWピン）は短さ優先**
- 幅1.0mm以上 + ループ面積最小 → それ以外の幅計算より重要

**JLCPCB 最小ルール確認**
- 最小トレース: 0.1mm（実用下限は0.15mm推奨）
- In3の銅塗り間クリアランス: 0.2mm以上

---

KiCadのNetクラス設定で最初に `POWER` クラス（1.0mm）と `HIGH_CURRENT`（1.5mm）を作っておくと楽です。必要であれば設定値をそのまま書き出します。

## 6層基板とは

銅箔の層が6枚重なった板です。

```
F.Cu   ← 表面（部品面）
In1    ← 内層1
In2    ← 内層2
In3    ← 内層3
In4    ← 内層4
B.Cu   ← 裏面（部品面）
```

層間はビア（穴）で繋ぎます。

---

## なぜ6層にしたか（このプロジェクトの理由）

| 問題 | 解決策 |
|------|--------|
| キースイッチがF.Cu全体を占有 | B.Cuにも部品配置層が必要 |
| USB3.0/HDMI/PCIeの高速信号 | 専用GND参照面が必要（インピーダンス制御） |
| 電源ベタ（VSYS/5V_SYS）を信号と分離 | 専用電源層が必要 |
| EMI対策（GNDベタ2枚） | 4層では足りない |

4層でも作れなくはないけど、高速差動ペアのインピーダンス管理と電源分離を両立するのが困難。

---

## 各層の役割（このプロジェクト）

```
F.Cu  → COL線 + キースイッチ配線（表面部品なし）
In1   → GNDベタ ← F.CuのEMI吸収・参照面
In2   → ROW線 + IC間信号配線
In3   → VSYS/5V_SYS/3V3 銅塗りゾーン + 信号の隙間配線
In4   → GNDベタ ← B.Cuの高速信号参照面
B.Cu  → IC実装 + IC配線 + USB3.0/HDMI/PCIe差動ペア
```

**ポイント**: 信号層の隣には必ずGNDベタがある設計。これがインピーダンス制御の基本。

---

## ビアの種類

| 種類 | 貫通 | コスト |
|------|------|--------|
| スルーホールビア | F.Cu〜B.Cu全貫通 | 安い（標準） |
| ブラインドビア | 表面〜内層のみ | 高い |
| バリードビア | 内層〜内層のみ | 高い |

**このプロジェクトはスルーホールビアのみ使う予定**。JLCPCBで安く作れる。

---

## 実際にKiCadで困るポイント（先に把握しておくべきこと）

1. **ビア配置**: In1/In4のGNDベタをビアで繋ぎまくる（ベタGNDの導通確保）
2. **层の切り替え**: KiCadでルーティング中に `+` / `-` キーで層切り替え
3. **DRCルール**: JLCPCBの6層ルール（0.1mmトレース/クリアランス）を先に設定
4. **電源ゾーン（In3）**: KiCadの「ゾーン塗りつぶし」機能でネットごとに領域指定

---

## RP2040 ↔ VL812 の許容距離

接続は **USB2.0 HS（480Mbps）の差動ペア（DP/DM）** なので：

---

### 結論から

**〜100mm なら問題なし。50mm以内が理想。**

USB2.0 HSは高速信号の中では比較的ゆるい規格。長さ制限より**インピーダンスとペア内等長**の方が重要。

---

### 守るべきルール（距離より優先）

| ルール | 値 |
|--------|-----|
| 差動インピーダンス | **90Ω** |
| ペア内等長（DP↔DM長さ差） | **±0.5mm以内** |
| ペア間隔（DP-DM間） | 0.15〜0.2mm（インピーダンス計算次第） |
| 他信号からのクリアランス | 3倍ルール（ペア幅の3倍以上離す） |

---

### このプロジェクトのレイアウト的には

```
配置メモより：
  RP2040 #1 → 中央やや左
  VL812    → 中央エリア
  RP2040 #2 → 右寄り
```

RP2040 #2 ↔ VL812 が一番距離があるケースで、B.Cu上を真っ直ぐ引ければ50〜60mm程度に収まるはず。全然問題ない範囲です。

---

### 注意点

- RP2040〜VL812 間はデバイス内部接続なので **USBLC6不要**（コネクタ直後だけでOK）
- GNDベタ（In4）を参照面にしてB.Cuで引く → インピーダンス計算しやすい
- **RP2040のUSBピン（Pin48/49）から直近でビア落として B.Cu に入る**のが最短

90Ωのトレース幅は後でJLCPCBのインピーダンス計算ツールで確認してから設定します。

## L3 ↔ VL812 の距離

### 結論：**できれば2mm以内、最大でも5mm**

pcb_layout_notesでも「最短必須（数mm以内）」に分類済みの組み合わせです。

---

### なぜ最短必須か

L3はVL812の**内蔵DC-DC（1.2Vコア生成）のスイッチングノード（LXピン）**に直結しています。

```
VL812 LXピン → L3 → 出力キャップ → GND → VL812内部
         ↑
    このループ面積がEMIのアンテナになる
```

ループ面積が大きいほど：
- 高周波EMIが増える
- スイッチングノイズが他の信号に乗る
- VL812自体の動作が不安定になるリスク

---

### 実装の優先順位

1. **L3をVL812のLXピン直近に配置**（同じ層、ビアなし直結が理想）
2. **LXノードのトレースは短く太く**（1.0mm以上）
3. **出力キャップ（10µFなど）もL3の隣**に置く
4. LXノードの銅面積は**必要最小限**（GNDベタで覆わない）

---

### VL812のLXピンがどこにあるか

VL812（QFN-76 / 9×9mm）のデータシートでLXピンの位置を確認して、そこから**基板外側方向**にL3を置くとトレースが短くなります。

---

## 何が問題か

```
B.Cu（IC実装面）の現実：
  [VL812] [RP2040] [PCM5102A] [TPA6132A2] ...
     ↑ICだらけの中を差動ペアが通らないといけない
```

ICのパッドやビアが密集してる中を、インピーダンスを保ちながら等長で引くのはかなり難しい。

---

## 現実的な対処法

### 案①：「差動ペア専用の通り道」を最初に確保する（推奨）

**IC配置の前に、差動ペアのルートを先に決める。**

```
右上エリア（M.2側）：
  FPC(PCIe) ─────────────────→ M.2ソケット
                ↑この帯域を空けてからICを置く

左上エリア（USB側）：
  J_EXT_C ──→ USBLC6 ──→ VL812
  J_EXT_A ──→ USBLC6 ──→ VL812
                ↑コネクタ〜VL812間を直線的に確保
```

部品配置のときに「ここは差動ペアが通る」エリアを先に決めて、ICはそこを避ける。

---

### 案②：一部の差動ペアをIn2に逃がす

| 信号 | 速度 | 候補層 |
|------|------|--------|
| USB3.0 SS | 5Gbps | **In2**（In1 GNDを参照）でも可 |
| HDMI | 1.65Gbps | **In2**で可 |
| PCIe Gen3 | 8Gbps | **B.Cuが無難**（In4 GNDを直下参照） |

PCIeは一番速いのでB.Cu + In4参照が理想。USB3.0とHDMIはIn2 + In1参照でも実用上問題ない。

---

### 案③：PCIeだけ別扱い

PCIeはM.2ソケット → FPCコネクタの**右上エリアだけで完結**するので距離が短い。ICが少ないエリアを選んで配置すればB.Cuでもそれほど辛くない。

---

## このプロジェクトで現実的な方針

```
B.Cu：PCIe Gen3 + IC実装（右上エリアに集約・ICで囲まない）
In2：USB3.0 SS + HDMI（信号通り道をIn2に逃がす）
```

これで「B.Cuが混みすぎて差動ペア引けない」問題はかなり緩和できます。

const int freq = 1000;   // 1kHz（ICの1MHzより十分低い）
