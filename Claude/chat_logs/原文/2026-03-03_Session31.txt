## Kill Switch の回路見直し提案

SW2 を「VSYSの物理カット」から **「Pチャンネル MOSFET を小型スライドスイッチで制御」** に変更する方が現実的です。

```
VSYS_BAT ─→ [P-MOS Source] ─→ [Drain] ─→ VSYS（負荷側）
                    │
              [Gate] ─ 100kΩ ─ VSYS_BAT（プルアップ）
                    │
              SW2（小型スライドスイッチ）─→ GND
```

| 状態 | SW2 | Gate電位 | Vgs | MOSFET |
|------|-----|---------|-----|--------|
| 通常動作 | 閉 | ≈GND | ≈−4V | ON |
| 緊急キル | 開 | ≈VSYS（プルアップ） | ≈0V | OFF |

**追加部品:**
- Pチャン MOSFET: **DMP3010LK3**（C20917）Vds=−30V / Id=−9A / SOT-23
- 100kΩ プルアップ（Gate→Source）
- 10kΩ（Gate とスライドスイッチの間）
- SW2: SS12F15 等の小型スライドスイッチ（0.5A で十分・SMDも選択可）

## F0506-16-BGR の確認

**RPi5 の PCIe FPC（16pin / 0.5mm ピッチ）と同仕様**です。公式仕様書で定義されているピン構成：

| ピン | 信号 |
|------|------|
| 1 | GND |
| 2 | PCIE_TX_P |
| 3 | PCIE_TX_N |
| 4 | GND |
| 5 | PCIE_RX_P |
| 6 | PCIE_RX_N |
| 7 | GND |
| 8 | PCIE_REFCLK_P |
| 9 | PCIE_REFCLK_N |
| 10 | GND |
| 11 | PCIE_PERST_N |
| 12 | PCIE_CLKREQ_N |
| 13 | PCIE_WAKE_N |
| 14 | 3.3V |
| 15 | 3.3V |
| 16 | GND |

PCIe x1 なのでそのまま NVMe SSD に繋げます。

## PCIe x1 の拡張性

M.2 M-key スロットを積んでおくと SSD 以外にも差し替えできます：

| カード | 効果 | 備考 |
|--------|------|------|

| **AI アクセラレータ** | 推論処理をオフロード | Coral M.2 Accelerator など / Cubie の仕様書にも明記 |
| **2.5GbE NIC** | 有線LAN追加 | RTL8125B 系の M.2 カード |
| **USB 3.2 コントローラ** | USB ポート増設 | PCIe → USB 変換 M.2 カード |
| **SATA コントローラ** | SATA ポート追加 | 用途は限定的だけど一応 |

## m2_ssd シート 設計案

```
5V_SYS → [RT9080 LDO] → 3V3_M2 → M.2コネクタ電源

J_PCIE_FPC (16pin ZIF)
  ├── TX_P/N → [100nF AC coupling] → M.2 PERp0/PERn0（SSD受信）
  ├── RX_P/N ─────────────────────→ M.2 PETp0/PETn0（SSD送信）
  ├── REFCLK_P/N ──────────────────→ M.2 REFCLK+/-
  ├── PERST_N ─────────────────────→ M.2 PERST#
  ├── CLKREQ_N ─── 10kΩ → 3V3_M2, ─→ M.2 CLKREQ#
  └── WAKE_N ────── 10kΩ → 3V3_M2, ─→ M.2 PEWAKE#
```

## FPC → M.2 全接続図

### 差動ペア（PCIe レーン）

```
FPC                              M.2
Pin2 PCIE_TX_P ──[100nF]──────── PERp0  ← SSD の受信側（+）
Pin3 PCIE_TX_N ──[100nF]──────── PERn0  ← SSD の受信側（−）
                                          ↑ AC結合が必要

Pin5 PCIE_RX_P ─────────────────── PETp0  ← SSD の送信側（+）
Pin6 PCIE_RX_N ─────────────────── PETn0  ← SSD の送信側（−）
                                          ↑ SSD 内部で AC結合済みなので不要
```

**TX/RX の命名に注意：**
- PER = PCIe **E**ndpoint **R**eceive（SSD が受け取る＝ホスト送信）
- PET = PCIe **E**ndpoint **T**ransmit（SSD が送る＝ホスト受信）

---

### リファレンスクロック

```
FPC Pin8 PCIE_REFCLK_P ─────────── REFCLK+  （直結・AC結合不要）
FPC Pin9 PCIE_REFCLK_N ─────────── REFCLK−
```

---

### 制御信号

```
FPC Pin11 PCIE_PERST_N ──────────── PERST#   （リセット / ホスト→SSD）

FPC Pin12 PCIE_CLKREQ_N ─┬────────── CLKREQ#  （SSD→ホスト / SSDがクロック要求）
                          └── 10kΩ ── 3V3_M2

FPC Pin13 PCIE_WAKE_N ───┬────────── PEWAKE#  （SSD→ホスト / スリープ解除）
                          └── 10kΩ ── 3V3_M2
```

---

### 電源

```
FPC Pin14, 15（3.3V）→ NC（A7Z からの電源は使わない）

3V3_M2（RT9080 出力）→ M.2 の 3.3V ピン全部
                        + 10µF ── GND（バルク）
                        + 100nF ── GND（バイパス）
```

---

### GND

```
FPC Pin1, 4, 7, 10, 16 → GND
M.2 の GND ピン全部    → GND
```

---

### 使わないピン

| M.2 信号 | 処置 |
|---------|------|
| PERp1/n1〜PERp3/n3（x2/x4 レーン） | NC |
| PETp1/n1〜PETp3/n3 | NC |
| DEVSLP | NC |
| LED1# | NC |

---

### KiCad 配置のコツ

- **100nF AC結合キャップ**（PERp0/PERn0 の手前）は 0402 を使い、PCBレイアウト時に M.2 コネクタの近くに置く
- CLKREQ# / WAKE# のプルアップ 10kΩ は Net Label 経由で 3V3_M2 に繋ぐだけで OK
- PERST# は特別な保護回路なしで直結で問題なし
