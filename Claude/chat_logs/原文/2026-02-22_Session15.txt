## power シート 検証結果

### ❌ 重大な問題（修正必須）

**BQ25895 CE ピン（Pin 9）→ GND に接続されている**

```
Pin 9 (CE, 99.06, 99.06)
  → wire → (99.06, 101.6) → GND power symbol
```

- BQ25895 の CE ピンは **Active HIGH**（High = 充電有効）
- 内部プルダウン搭載のため、GND に引っ張ると **充電ハードウェアが完全に無効化**
- I2C で CHG_CONFIG=1 にしても、CE=Low なら充電は動かない
- RP2040 GPIO への CE 割り当ても無し

**修正**: CE → `+3V3` に変更（充電をハードウェアで常時有効化）

---

### ⚠️ 軽微な問題（修正推奨）

**L1 の Value が未設定（"L_Small" のまま）**

```
L1: "L_Small"  ← シンボル名のまま
L2: "1µH / 3A" ← TPS61023用、正しく設定済み
```

       while queue:

                   tag = 'GLB:'+name

           for (x1,y1),(x2,y2) in wires:

ツェナーダイオード（Zener diode）は「一定電圧以上になったら逆向きに電流を流す」特殊なダイオードです。
