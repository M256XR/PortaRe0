### SBC USB-C 2ポートの役割分担

```
USB-C 2.0 (電源+データOTG)  → J_SBC_PWR  : 5V_SYS → SBC電源供給
USB-C 3.0 (USB+DisplayPort)  → J_SBC_USB3 : VL812 upstream（USB hub）
```

---

### J_SBC_PWR（SBC USB2.0 OTG ポート用）

- Main PCBが **DFP（電源供給側）** の役割
- CC1/CC2: **Rp = 10kΩ → 5V_SYS**（5V/3A アドバタイズ）
- VBUS: **5V_SYS**
- DP/DM: NC（データ不要なら）

### J_SBC_USB3（SBC USB3.0 → VL812 upstream）

- Main PCBが **UFP（デバイス側）** の役割
- CC1/CC2: **Rd = 5.1kΩ → GND**
- VBUS: **5V_SYS に接続**（SBCがUSB列挙できるよう）
- DP/DM → VL812 upstream USB2
- SS TX+/- RX+/- → VL812 upstream USB3

> DP Alt Modeはソフト側のネゴシエーションが必要なので、VL812との接続で誤起動はしない。

## HDMIの5Vについて

**HDMI Pin 18 (+5V)** は規格上含まれていますが、役割が違います：

| 5V | 用途 | 電流 |
|----|------|------|
| HDMI Pin 18 | HPD（ホットプラグ検出）回路用 | **最大55mA** |
| Micro-USB 5V | コントローラ基板のメイン電源 | **数百mA〜** |

→ FPCにHDMI 19信号を通せばPin 18の5Vも自然に含まれます。  
ただし**55mAしか流せない**ので、コントローラ基板のメイン電源にはなりません。

## FPC直付けコネクタ

```
main PCB側                           SBC側（補強板付き）
┌────────┐                    ┌──────────────────────────┐
│ZIF     │                    │ ←補強板(スティフナー)→   │
│コネクタ │ ~~~ FPC本体 ~~~~~ │ [Micro HDMIオス] [USB-Cオス×2]│
└────────┘                    └──────────────────────────┘
```

FPCの端に**スティフナー（補強板）**を貼って、その上にコネクタを直付けするのは商業製品でも普通にやっている設計です。FPCメーカーに発注するときにコネクタ実装込みで頼めます。

## 一緒にするか分けるかの決め手

**① 信号品質の問題**

| 信号 | 必要インピーダンス |
|------|-----------------|
| HDMI TMDS | 100Ω差動 |
| USB3.0 SS | 90Ω差動 |

同一FPCだと片方に最適化できない。ただし**短距離（10〜15cm程度）なら許容範囲内**のことが多い。

**② 物理的制約（これが本質）**

Cubie A7ZのMicro HDMIとUSB-Cポートが**同じ辺に近接しているか**どうかで決まります。

- 同じ辺に並んでいる → 1本のスティフナーで届く → **まとめてOK**
- 違う辺 / 離れている → 物理的に無理 → **分ける必要あり**

| ずれの種類 | サブ基板 | FPC（スティフナー付き） |

- SBC端のコネクタ位置精度は**どちらも同じ問題**
- FPCの優位点は「**メインPCBの取り付け位置の遊びを吸収できる**」こと
- 作り直しが必要になったときFPCの方がコストが低い
