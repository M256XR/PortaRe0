## 電源ルーティングの優先順について

結論から言うと、**「広く使われてるから3V3を先に」は逆効果になりやすい**です。

### なぜ太いラインを先にすべきか

太いトレース（VSYS/5V_SYS の1.5〜2mm+）は：

- **取り回しの自由度が低い**（曲がれる場所・通れる隙間が限られる）
- **後から入れようとすると3V3トレースに行く手を塞がれる**
- 短く・直線的に引くほど低抵抗・低インダクタンス → 後回しほど迂回させるはめに

3V3は逆に：

- トレース幅0.3〜0.5mmと細く **隙間を縫って通しやすい**
- 分岐が多くても柔軟にルーティングできる
- 多少迂回しても電圧降下は無視できる

### 推奨順（再確認）

```
1. GNDベタ（Fill Zone）
2. VSYS / 5V_SYS（最太・最短優先）
3. VBAT〜BQ25895 間（大電流）
4. SYS〜TPS61023〜HUB_5V
5. 3V3_HUB / 3V3_M2（派生レール）
6. 3V3（AP2112K出力 → 各IC）  ← ここ
7. スイッチングノード（L1/L2など）
8. 差動ペア（USB SS / PCIe）
9. 一般信号
```

### 3V3を「先に」やりたくなる気持ちへの対処

配線箇所が多くて全体像を掴みたいなら、**ラッツネスト（未配線の接続線）を3V3だけ表示** してから太いラインのルートを確保するのがベターです。

## VL812エリアの具体的な対策

### 問題の構造

```
VL812周辺に集中するネット:
  5V（太い・幹線）
  HUB_3V3（VL812 IOレール）
  HUB_1V2（VL812コアレール）← 一番細いが一番局所的
```

5Vを先に引くと残り2本の逃げ道がなくなる → **局所的には HUB_1V2 → HUB_3V3 → 5V の順**が合理的。

### 根本解決案：6層構成を活かす

このプロジェクト6層なので、**5VをIn1かIn2のベタ（銅べた充填）にする**のが本来の姿です。

```
F.Cu   : 信号・細い電源
In1    : GND or 5Vプレーン  ← 5Vをここに
In2    : 3V3プレーン or 高速信号
In3    : 信号
B.Cu   : 信号・大電流トレース（VSYS/VBAT）
```

こうすると5Vはビア1本で各ICにドロップできるため、**表面での5Vトレースが不要**になり VL812周辺がすっきりします。

BQ25895の割り込み出力ピンです。充電状態の変化（満充電・エラー等）をRP2040 #1のGP19に通知する信号線です。

[User]

[Claude]
LED電流は数mAなので**0.1〜0.15mm**で十分です。

距離が短ければ数mm程度の誤差は許容範囲です。
