## 考え方

KiCadの「F.Cu（表）」「B.Cu（裏）」は単なるラベルで、**自分でどちらを「表」にするか決めていい**です。

このプロジェクトの物理的な向き：

```
[ユーザー手側]
─────────────────
  スイッチ・キーキャップ  ← F.Cu（表）にスイッチ
─────────────────  PCB
  IC・パッシブ部品       ← B.Cu（裏）にIC類
─────────────────
[ケース底面]
```

つまり：
- **F.Cu = スイッチ面**（ユーザー側・上面）
- **B.Cu = IC面**（ケース側・下面）

これが一番自然な定義です。

---

## 実際の配置

- スイッチ（SKRPABE010/SKSCLBE010）→ **F.Cu**（そのまま）
- RP2040・BQ25895・VL812等のIC → **B.Cu**（`F`キーでフリップ）
- スイッチが占めないエリア（PCB端の隙間）にICを寄せる

スイッチが63個で135×77mmだとほぼ全面スイッチになるので、IC類はほぼB.Cu行きになりますね。

## 4層で足りる理由

| 層 | 用途 |
|----|------|
| F.Cu | スイッチ + COL線 + 一部信号 |
| In1.Cu | GNDべた（べた銅・切らない） |
| In2.Cu | 電源べた（VSYS/5V_SYS/3V3エリア分割） |
| B.Cu | IC + ROW線 + USB/HDMI差動ペア |

キーボードマトリクスは単純な格子配線なので層を食わない。差動ペア（USB3.0/HDMI）はB.Cuに集中させれば2層で処理できます。

## キツいポイント

- **VSYSの極太パターン**（5〜6A）→ In2.Cuのべたで面で流す
- **F.CuとB.Cuが混雑**する可能性 → ICを右半分に集めることで緩和

JLCPCBだと6層は4層比で約2〜3倍になります。1枚試作なら許容範囲ですが、4層で詰まってから考えても遅くないです。

**結論：まず4層で進めて、ルーティングで詰まったら6層に切り替え**が現実的です。どのへんが特に心配ですか？
