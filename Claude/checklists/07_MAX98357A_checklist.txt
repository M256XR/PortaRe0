■ MAX98357A ピン配置 (WLP-9):
  A1: ~SD_MODE~ (シャットダウン/チャンネル選択)
  A2: VDD (電源)
  A3: OUTP (スピーカー+)
  B1: DIN (I2S データ入力)
  B2: GAIN_SLOT (ゲイン/タイムスロット設定)
  B3: OUTN (スピーカー−)
  C1: BCLK (I2S ビットクロック)
  C2: GND
  C3: LRCLK (I2S L/R クロック)

■ SD_MODE 設定値 (データシートより):
  フローティング: 左チャンネル出力 (Left)
  GND〜220kΩ経由VDD間の電圧: 右チャンネル出力 (Right) ← 典型値: 220kΩをGND側へ
  GND 直結: シャットダウン
  VDD 直結: シャットダウン

■ GAIN_SLOT 設定値:
  フローティング: 9dB ゲイン / スロット0
  GND 直結: 3dB ゲイン / スロット0
  VDD 直結: 12dB ゲイン / スロット0
  100kΩ → GND: 6dB ゲイン
  その他: データシート Table 2 参照

[ ] I2S バス: BCLK/LRCLK は U9 と U15 で共有 (並列接続)
[ ] SDIN: U9 と U15 で共有 (同じ I2S データバス)
    注意: LRCLKの極性によりL/Rが自動割り当てされる
    SD_MODE が機能しているか + LRCLK がどちらの ch を先に出力するかが重要
[ ] SD_MODE GP3 が LOW の時: 両方シャットダウン?
    → GP3 は「スピーカー ON/OFF 制御」として使用。
       U9: SD_MODE = GP3 (フローティングに近い = Left)
       U15: SD_MODE = GP3 経由 220kΩ = Right
       GP3 LOW → U9: GND直結 = シャットダウン, U15: 220kΩ経由 ≈ GND = シャットダウン? → OK
[ ] バイパスキャップが U9 と U15 それぞれに配置されているか
[ ] スピーカー極性: OUTP=+, OUTN=- を一致させること (2個とも同じ向き)
