================================================================================
層構成（6層確定）
================================================================================

F.Cu  : COL線 + キースイッチ（表面全体）→ IC配線NG
In1   : GND ベタ（配線なし・ビア貫通のみ）
In2   : ROW線 + IC配線 1層目 + USB3.0 SS差動ペア + HDMI差動ペア
In3   : 電源ゾーン（VSYS/5V_SYS/3V3 ゾーン分割）+ IC配線 2層目（隙間）
In4   : GND ベタ（配線なし・B.Cuの参照面）
B.Cu  : IC実装面 + IC配線 + PCIe Gen3差動ペア（右上エリア限定・IC少）

※ In3は電源ゾーン銅塗りつつ隙間に信号を通す共用層
※ USB3.0 SS・HDMIをIn2に逃がした理由: B.CuはIC密集でインピーダンス管理困難
※ PCIeはM.2ソケット+FPCコネクタのみで周辺IC少 → B.Cuでも問題なし
※ In2はIn1 GNDが直上参照面 / B.CuはIn4 GNDが直上参照面（両層ともインピーダンス制御成立）

================================================================================
大まかな配置方針
================================================================================

[上端エッジ]
  肩L | SW1(PowerSW) | J4(Battery) | J_USB_PWR | SW2(KillSW)
  | J_EXT_A(USB-A) | J_EXT_C(USB-C ext) | J9(AudioJack) | 肩R
  ※ J_HDMI_CTRL はF.Cu表側（HDMIコントローラ基板が表側に来るため）

[左上エリア]
  BQ25895(U1) + L1 + TPS61023 #1(U2) + L2 + AP2112K(U3)
  → VSYS極太パターンを最短に
  → J_USB_PWRの真下付近

[右上エリア]
  TPS61023 #2(U7) + L4（J_EXT_C/A の近く）
  M.2ソケット(CN1) 横向き配置 + RT9080(U16) + FPC6(SBC_PCIE)
  → PCIe FFC 10cm以内で接続可能（Gen3 x1 は10cmで問題なし）

[上中央エリア]
  FPC類（FPC2:J_SBC_HDMI / FPC4:J_SBC_USB_2.0 / FPC5:J_SBC_USB_3.1）
  → バッテリー上エリア・発熱ほぼゼロなので問題なし

[中央エリア]
  VL812(U4) + W25Q32(U5) + TPS2042BDR(U10) + USBLC6×2(D5/D6)
  RP2040 #1(U6) → キーマトリクス中心付近（中央やや左寄り）
  RP2040 #2(U11) → 右寄り（オーディオICと近く）

[右側エリア]
  PCM5102A(U13) + TPA6132A2(U14) ← 近接配置
  RP2040 #2(U11) + W25Q32(QSPI Flash)

[右下エリア]
  MAX98357A L/R(U9/U15) → J2/J3スピーカーコネクタの近く
  アナログスティック(Stick1)

[左下エリア]
  バッテリー（606090 / 90mm×60mm）
  J4(Battery) は上端に配置・左端をケーブルが縦走

================================================================================
発熱量まとめ（バッテリー上配置可否）
================================================================================

--- バッテリー上NG（0.5W以上 または 高電流経路） ---

部品          発熱概算   理由
----------    --------   ----------------------------------------
BQ25895(U1)   0.5〜1W    充電時スイッチング損失（効率92%、5V×2A入力）
TPS61023 #1   0.3〜0.5W  昇圧スイッチング損失
L1(2.2µH)     0.23W      I²×DCR = (2A)²×0.058Ω
L2(1µH) #1    0.42W      I²×DCR = (3.75A)²×0.030Ω
VL812(U4)     0.5〜1W    USB3.0ハブ動作時

--- 許容範囲（バッテリー上OK） ---

部品              発熱概算    備考
--------------    --------    ----------------------------------------
AP2112K(U3)       0.34W       (5-3.3V)×200mA・ギリギリ許容
TPS61023 #2       0.05W       軽負荷（外部USB小型デバイス想定）
L4(1µH) #2        0.02W       軽負荷
L3(10µH) VL812用  0.07W       1.2V出力側電流が小さい
RP2040 ×2         各0.1〜0.2W アイドル時低消費
オーディオIC群     合計0.2〜0.3W PCM5102A/TPA6132A2/MAX98357A
抵抗・コンデンサ  極小         問題なし

--- バッテリー熱保護対策 ---
1. カプトンテープ（ポリイミド）をバッテリー表面に貼る（熱伝導率0.12W/mK）
2. エアギャップ確保（スタンドオフで1〜2mm）
3. BQ25895/TPS61023 #1/L1/L2 をバッテリーエリア外（左上端）に固定

================================================================================
近接配置が必要な部品ペア
================================================================================

--- 最短必須（数mm以内） ---

ペア                                  理由
------------------------------------  ----------------------------------------
L1 ↔ BQ25895 [SWピン]                スイッチングノードのループ最小化（EMI対策）
L2 ↔ TPS61023 #1 [SWピン]           同上
L4 ↔ TPS61023 #2 [SWピン]           同上
L3 ↔ VL812 [LXピン]                 同上
Y1(25MHz) ↔ VL812                   発振ループ面積最小化
Y2/Y4(12MHz) ↔ RP2040 #1/#2         同上
クリスタル負荷キャップ ↔ クリスタル   発振ループに入らないよう直近に
W25Q32(U5) ↔ VL812                  SPI高速配線
W25Q32(QSPI) ↔ RP2040 #1/#2         QSPI高速配線（各RP2040用Flash）
デカップリングキャップ ↔ 各IC電源ピン  電源ピンの真横0.5〜1mm以内

--- 近い方がいい（1cm以内目安） ---

ペア                          理由
----------------------------  ----------------------------------------
USBLC6(D5) ↔ J_EXT_C         ESD保護はコネクタ入口直後
USBLC6(D6) ↔ J_EXT_A         同上
TPS2042BDR(U10) ↔ VL812(U4)  USBHPE/USBHOC制御線を短く
PCM5102A(U13) ↔ TPA6132A2(U14) アナログ音声信号を短く
MAX98357A(U9/U15) ↔ J2/J3    スピーカー出力電流を短い経路で
SSREXT抵抗(R18) ↔ VL812 Pin1  アナログ基準抵抗
RT9080(U16) ↔ CN1(M.2ソケット) 3V3_M2配線を短く

--- 高速差動ペア（別途等長配線ルール適用） ---

信号           規格    層       インピーダンス
-----------    ------  ------   --------------
USB3.0 SS      5Gbps   B.Cu     90Ω差動
HDMI           1.65G   B.Cu     90Ω差動・等長
PCIe Gen3 x1   8Gbps   B.Cu     85〜90Ω差動・等長
               ↑ いずれもIn4 GNDを参照面とする

================================================================================
IC間距離目安（JLCPCBルール: 最小トレース0.1mm/クリアランス0.1mm）
================================================================================

VL812（QFN-76 / 0.4mmピッチ）周囲  : 4〜5mm確保推奨
RP2040（QFN-56 / 0.4mmピッチ）周囲 : 3〜4mm確保推奨
小型IC同士                          : 3mm程度
デカップリングキャップのみ           : 0.5〜1mm（IC電源ピン直近）

================================================================================
電源フロー（左→右）
================================================================================

バッテリー(左下) → J4(左上) → BQ25895(U1) → TPS61023 #1(U2)
                                              → 5V_SYS(In3プレーン) ──→ VL812(中央)
                                              → 3V3(AP2112K U3)  ──→ RP2040×2
                                              → 3V3_M2(RT9080 U16) → M.2(右上)
                             ↘ TPS61023 #2(U7) → USB_5V_SYS → J_EXT_C/A(右上)
