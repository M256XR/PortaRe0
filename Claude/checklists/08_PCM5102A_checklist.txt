■ PCM5102A ピン配置 (TSSOP-20):
  Pin 1:  CPVDD   — チャージポンプ VDD (= DVDD)
  Pin 2:  CAPP    — チャージポンプ + キャップ
  Pin 3:  CPGND   — チャージポンプ GND
  Pin 4:  CAPM    — チャージポンプ − キャップ
  Pin 5:  VNEG    — 負電圧出力 (チャージポンプ出力)
  Pin 6:  OUTL    — アナログ L チャンネル出力
  Pin 7:  OUTR    — アナログ R チャンネル出力
  Pin 8:  AVDD    — アナログ電源 (3.3V)
  Pin 9:  AGND    — アナログ GND
  Pin 10: DEMP    — デエンファシス制御
  Pin 11: FLT     — フィルタロールオフ選択
  Pin 12: SCK     — システムクロック (SCK-less モード時 GND or NC)
  Pin 13: BCK     — I2S ビットクロック
  Pin 14: DIN     — I2S データ入力
  Pin 15: LRCK    — I2S L/R クロック
  Pin 16: FMT     — データフォーマット選択
  Pin 17: XSMT    — ソフトミュート (LOW = ミュート)
  Pin 18: LDOO    — 内部 LDO 出力 (バイパスキャップのみ)
  Pin 19: DGND    — デジタル GND
  Pin 20: DVDD    — デジタル電源 (3.3V)
